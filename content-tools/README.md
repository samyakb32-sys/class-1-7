# Content generation tools

## generate_maths_seed.py

Generates `app/src/main/assets/seed/maths.json` — the trilingual (EN/MR/HI)
Maths curriculum for Classes 1–7. Run from the repo root:

```bash
python3 content-tools/generate_maths_seed.py
```

It's template-based, not hand-written question-by-question: a small set of
question *shapes* (addition, subtraction, multiplication, division, place
value, fractions, percentages, ratio, simple equations, perimeter/area,
integers, word problems) get instantiated with randomized numbers per
chapter. `random.seed(42)` makes output reproducible — rerunning without
changing the script gives the same 392 questions back.

**Why this approach for Maths specifically:** arithmetic translates cleanly —
"{a} + {b}" is trilingual by just translating the sentence frame once, then
reusing it for any numbers. This doesn't work for the language subjects.

**English / Marathi / Hindi still need real content.** Vocabulary, grammar,
and reading comprehension aren't proceduralizable the same way — there's no
"template + random numbers" equivalent for "which word means X" or a reading
passage. Those three subjects need either hand-authored questions per
chapter, or a different generation strategy (e.g. drawing from a curated word
list per class level with human review of the trilingual translations before
they ship to children). Neither is built yet.

**Before shipping any of this to real students:** the trilingual phrasing
here was generated by an AI, not reviewed by a Marathi/Hindi-speaking
educator. Grammar and phrasing should be checked, especially for the less
common templates (ratio, percentage, algebra word problems) where sentence
structure is more complex than simple arithmetic prompts.

## What's still needed for the full ~2,000-question spec

- Maths: **done** — 35 chapters, 392 questions, all 7 classes
- English: not started
- Marathi: not started
- Hindi: not started

Spec asks for 5–7 chapters × 10–15 questions per subject per class. Maths
landed at 5 chapters × ~11 average per class, which is within spec range but
at the lower end — extending `generate_maths_seed.py`'s per-chapter counts
or adding 1–2 more chapters per class would close the gap if needed.
